# AlekS DTS: совместимость и безопасная установка на другие LG

## Подтверждённые профили

| Телевизор / платформа | Изолированная проверка | Подключение в штатный плеер |
| --- | --- | --- |
| LG 65NANO896PC, webOS 6.6, ARMv7, GStreamer 1.16.2 | DTS Core / AC3 PASS | DTS Core 5.1 и регрессия DVB-C подтверждены |
| LG UP75006LF, ARMv7, R278 | DTS Core / AC3 PASS по сообщению владельца | Владелец сообщил, что воспроизведение работает; расширенная регрессия не документирована |
| LG 43NANO85A6A, firmware 43.22.74, kernel aarch64, **media ELF32 ARM**, GStreamer 1.24.10 | DTS 2.0/5.1 + программный AC3 PASS; PREVIEW `verify` PASS; R279 `install`/`rollback` PASS | **DTS в Lampa: звук подтверждён владельцем после повторного открытия фильма**; реальный ALSA PCM работает. Штатный LG Media Player, холодные старты и многократная регрессия ещё не проверены; публичный релиз преждевременен |
| Любые другие модели, версии ABI или GStreamer | **Не проверено** | Не устанавливать без предварительной диагностики |

Нельзя определять архитектуру медиаплеера только по `uname -m`: на кухонном LG ядро ARM64, а `umediaserver` и GStreamer 32-битные.

## Первый шаг на неизвестной модели

В root SSH устройства (или через `ares-novacom --device <профиль> --run "..."`) запустите **только read-only** диагностику:

```sh
curl -fLsS 'https://raw.githubusercontent.com/aerolit266/AlekS-DTS-webOS/cec9b978e65750a51a12ca21aeaf32adef691581/tools/public-compatibility-check.sh' -o /tmp/aleks-dts-compat.sh &&
printf '%s  %s\n' '70da08090cc9d1c25a9b069c22f072882384234b2e5203d130a7d9b76f664d44' /tmp/aleks-dts-compat.sh | sha256sum -c - &&
sh /tmp/aleks-dts-compat.sh
```

Присылайте в [Issues](https://github.com/aerolit266/AlekS-DTS-webOS/issues) модель, webOS, фактический ELF ABI, GStreamer, статус встроенного AC3 и тестовый результат. Секреты, ключи SSH, содержимое `umediaserver.env` и приватные данные **не публикуйте**.

**R287, 22.11.2026 — повторная проверка 65 секунд:** 6/6 измерений `starfish-media` PID20727 и три DTS-модуля стабильны, `umediaserver`/`audiooutputd` активны, `codec=dts` 6/6. ALSA PCM6 `RUNNING` 6/6, аппаратный указатель увеличился на 3 121 152 кадра за 65 секунд (порядка 48 кГц); RSS процесса 118024→118032 КиБ (+8 КиБ), без смены PID. **Это проверка воспроизведения и буфера, не запись ненулевого аудиосигнала.** [R287 read-only](tools/monitor-webos26-dts-output-r287.sh).

**Аппаратный путь PCM (R286, 22.11.2026):** во время работающего DTS на кухне ALSA MARS PCM6 в состоянии RUNNING, формат S16_LE, 2 канала, 48000 Гц; `hw_ptr` увеличивается. Три замера R285 подтвердили стабильность процесса и RSS. Это проверка реального PCM-выхода, но не прямое измерение звука на динамиках. [Read-only диагностика R286](tools/check-webos26-audio-output-r286.sh).

**Повторное открытие фильма (22.11.2026):** DTS заработал сразу, без переключения на AC3 — проверено владельцем. Дополнительно удалённо через AlekS Core подтверждены активные umediaserver/audiooutputd, три DTS-библиотеки в новом starfish-media, codec=dts, контрольные суммы и переменные процесса. Причина первоначальной тишины не установлена; холодная загрузка ТВ и полная регрессия не проверены.

**История первого сбоя (22.11.2026):** три DTS-дорожки «Матрицы» изначально были без звука, переход AC3→DTS восстановил звук на всех трёх. Позднее полное закрытие и повторное открытие фильма дало звук DTS **сразу, без AC3**. Первоначальную тишину пока не удалось воспроизвести повторно; причина неизвестна.

**Первый отрицательный полевой тест (исторический, 22.11.2026):** DTS-дорожки были без звука до переключения на AC3. Этот результат сохранён как регрессионный случай, **не как текущее состояние**: в повторной сессии DTS звук заработал. Массовое распространение DTS для webOS 26 всё ещё не разрешено без холодного запуска и регрессии штатного плеера.

**Результат скрипта проверки окружения (22.11.2026):** установщик, SHA256 и фактические переменные `umediaserver` PASS; `RESULT=CONFIG_AND_PROCESS_ENV_PASS; NATIVE_AUDIO_NOT_YET_TESTED` означает только, что **сам скрипт не измеряет звук**. Позднее пользователь подтвердил DTS в Lampa, а R286/R287 подтвердили аппаратный PCM-буфер. Прослушивание в штатном LG Media Player отдельно **не проверено**, поэтому общественный релиз для webOS 26 преждевременен.

## Проверка DTS через Lampa на LG

Наш каталог приложений для Homebrew Channel: `https://gamefree24.ru/webos/repository.json`. На 22.11.2026 он отдаёт валидный JSON `packages`, содержит `lampa.tv` 2.3.0 и `mybylampa.tv` (lampa+) 2.3.0. Контрольный IPK lampa+ с внешнего источника соответствует SHA256 `0f6014790e6cb610cb1e53314b4f608483bcf8472589314ce86914c9126bb20c`.

Для webOS shell подготовлен [скрипт открытия штатного окна добавления репозитория](tools/open-aleks-repo-homebrew-channel.sh). Он запускает `org.webosbrew.hbchannel` через Luna `applicationManager/launch` с `launchMode=addRepository`. Пользователь должен нажать **Add repository** на экране и обновить каталог. Скрипт **не изменяет** настройки DTS и не устанавливает IPK.

Важно: тест DTS в Lampa не заменяет отдельного теста в штатном плеере LG. Доступность каталога и работа IPK зависят от сети телевизора и внешнего источника пакета.

## Порядок установки

1. Определить профиль и проверить загрузку всех компонентов; не отключать ABI-защиту.
2. Провести DTS 2.0, DTS 5.1 и AC3 в **изолированном** GStreamer.
3. Проверить текущее состояние `umediaserver.service`, пути `EnvironmentFiles`, `/var`, потенциальные чужие DTS-плагины, доступность recovery и отката.
4. Создать защищённую резервную копию исходной конфигурации. Применять изменения исключительно в `/var`/Homebrew, **не** в штатных системных библиотеках.
5. После установки подтвердить контрольные суммы и наличие способа отката; затем полностью перезагрузить.
6. Проверить DTS 2.0/5.1 в штатном плеере, обычные AC3/AAC, DVB, сторонние плееры и стабильность нескольких перезагрузок. При регрессии откатить.

**Не запускайте установщик webOS26-кандидата на других LG:** он сознательно проверяет конкретный медиа-ABI/версию GStreamer, раздел eMMC `/dev/mmcblk0p59` и владельца медиаслужбы. Этот механизм необходим для первого полевого теста и должен стать адаптивным только после проверок на других моделях.

Для совместимых старых ARMv7/GStreamer 1.16 предусмотрен [install-universal.sh](install-universal.sh), сначала запускайте `verify`. Для webOS26 до подтверждения штатного медиаплеера используется только профиль кухни, документация в [README.md](README.md).

**Статус:** поддержка других моделей расширяется по мере проверенных аппаратных тестов. Универсальной гарантии работы на всех LG нет.
