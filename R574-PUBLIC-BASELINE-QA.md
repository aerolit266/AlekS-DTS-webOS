# R574 — проверка совместимости с публичной R278

Дата: 26.11.2026. Статус: лабораторная проверка, не разрешение на установку.

## Методика

Использован оригинальный общедоступный архив R278. Его SHA256 совпадает с контрольной суммой стабильного установщика. В отдельной ARM-лаборатории сравнивались исходный набор из четырёх плагинов и тот же набор с единственным изменением — новой обёрткой R574. Дополнительные экспериментальные маршрутизаторы не использовались. Штатный GStreamer 1.16.2; синтетические файлы из публичного архива; вывод в файл, без физического воспроизведения.

## Результаты

| Сценарий | Результат |
| --- | --- |
| R278, DTS Stereo S16LE | PASS |
| R278, DTS 5.1 S16LE | PASS |
| R574, DTS Stereo S16LE | PASS |
| R574, DTS 5.1 S16LE | PASS |
| R574, DTS 5.1 F32LE | PASS |
| R574, DTS 5.1 S32LE | PASS |
| R574, выбор между S16LE stereo и F32LE 5.1 | PASS: F32LE 5.1 |
| R574, выход только stereo | PASS: S16LE 2.0 |

Все восемь прогонов завершились EOS, каждый дал 48 128 PCM-кадров на 48 кГц, во всех ожидаемых каналах обнаружены ненулевые выборки. В F32LE не обнаружено NaN/Inf. Стерео и 5.1 в S16LE побайтно совпали между R278 и R574.

## Независимый контроль AC3 и восстановления

- AC3 5.1 через штатный программный декодер: исходная и новая конфигурации выдали идентичные PCM-данные F32LE, 48 кГц, 6 каналов. Обёртка AlekS DTS в этом явном AC3-маршруте не выбиралась.
- После восстановления исходной обёртки все четыре файла плагинов совпали с оригинальным архивом R278.
- Повторный DTS 5.1 после восстановления дал побайтно тот же PCM, что и исходный прогон R278.

Это лабораторное восстановление файлов плагинов, а не проверка отката системной конфигурации на телевизоре. Не проверялись реальный вывод через HDMI/eARC, автоматический выбор декодера в каждом приложении и все конкурентные смены форматов.

## Предварительная диагностика

Опубликованный check-r574-compat.sh повторно скачан по закреплённой ссылке, SHA256 совпадает. Синтаксис sh и BusyBox sh проверен. Классификация девяти синтетических ELF-заголовков/случаев в каждой оболочке: 18/18 PASS. На обычном x86-64 Linux утилита не признала ABI совместимым и не разрешила установку. Проверка самой утилиты на LG пока не завершена.

## Статус публикации

Двоичный пакет и универсальное обновление R574 пока не опубликованы. Требуется проверить перенос и откат конфигурации на поддерживаемых моделях, завершить проверку прав на распространение новой обёртки и комплектности применимых лицензий. Исходники, локальные конфигурации и внутренние материалы лаборатории в данный отчёт не включены.

Стабильная версия R278 остаётся в main.
