# AlekS DTS R574 — предварительное описание экспериментальной версии

**Статус: предварительная документация, не готово к публичной установке.** Стабильная R278 и её универсальный установщик остаются в основной ветке main. В этой ветке пока нет нового установочного пакета. Не используйте унаследованный установщик R278 для установки R574.

## Что изменилось по сравнению с R278

- Сохранено проверенное ядро декодирования DTS Core; переработана обёртка GStreamer.
- Добавлен выбор форматов PCM S16LE, F32LE и S32LE. При отсутствии ограничений предпочтителен S16LE.
- При согласовании с downstream сначала проверяются варианты, сохраняющие исходную частоту, число каналов и раскладку, затем совместимые варианты преобразования. Например, при выборе между S16LE stereo и F32LE 5.1 предпочтителен F32LE 5.1.
- Добавлен экспериментальный строгий режим сохранения каналов (по умолчанию выключен). Не следует принудительно использовать его на стереовыходах.
- Улучшена обработка RECONFIGURE и смены форматов PCM, сброс состояния при остановке.
- Расширена ограниченная диагностика PCM: F32LE, проверка конечности выборок, учёт смены CAPS, синхронизация диагностических счётчиков.

Это декодирование DTS Core в PCM, а не DTS-HD MA lossless, DTS:X или лицензированный DTS passthrough. Не обещается вывод PCM 5.1 через любой HDMI ARC/eARC, оптический выход или ресивер. Фактический результат зависит от всего медиатракта.

## Проверено

| Проверка | Результат |
| --- | --- |
| Лаборатория ARM QEMU, штатный LG GStreamer 1.16.2, дополнительные сценарии R575 | 30/30 PASS |
| Контролируемая смена S16LE6 → F32LE6 → S16LE2 → S32LE6 | 10/10 PASS |
| Остановка и повторный запуск при RECONFIGURE | 8/8 PASS (1280 попыток событий) |
| Интеграционные лабораторные сценарии с экспериментальным маршрутом R571 | 12/12 PASS (маршрут не входит в домашний пакет R574) |
| Изолированные проверки на LG 65NANO896PC | 7/7 PASS |
| Ограниченные проверки PCM на трёх участках тракта | 18/18 PASS |

На домашнем LG 65NANO896PC после переключения конфигурации и перезагрузки подтверждены путь плагинов R574 и активность umediaserver/audiooutputd. Физическое звучание в Lampa, холодный старт DTS без AC3 и вывод PCM 5.1 на Yamaha пока не подтверждены. Не доказана корректность всех конкурентных смен разных CAPS. Прирост скорости и качества звучания не измерен.

## Предварительные требования к публичной сборке

Использовать архитектуру существующего универсального установщика R278: проверка реального ABI медиапроцессов (не только uname), контроль целостности, изолированные проверки, резервирование и проверяемый откат. Не распространять домашнюю конфигурацию. Проверить обновление поверх R278, совместимость GStreamer и комплектность применимых лицензий/исходников. До завершения этих проверок установка R574 для сторонних пользователей не предлагается.

## План испытания на OLED77 B1 с Yamaha RX-A4A

После появления проверенной публичной сборки и её установки владельцем:
1. Записать модель LG, версию webOS, прошивку, модель ресивера, тип соединения и настройки звукового выхода. Не менять настройки между сравниваемыми тестами.
2. Полностью перезагрузить ТВ. В одном и том же плеере запустить DTS 5.1 первым, не переключаясь предварительно на AC3.
3. Проверить слышимость, входной формат и число каналов на Yamaha (информация о входном сигнале, не режим апмикса). Проверить тестовый файл с раздельными каналами.
4. Повторить для DTS Stereo и AC3 5.1. Проверить DTS ↔ AC3, паузу, перемотку и повторный запуск.
5. Повторить холодный запуск и сравнить результаты с предыдущей версией. При тишине, сбоях или ухудшении прекратить тест; использовать документированный откат соответствующей сборки после его проверки.

Для отчёта: модель и прошивка, версия AlekS DTS, плеер, codec, HDMI ARC/eARC или другой выход, формат входа Yamaha, число каналов, слышимость, результат после перезагрузки и переключения. Не публиковать IP-адреса, пароли, ключи или личные данные.
