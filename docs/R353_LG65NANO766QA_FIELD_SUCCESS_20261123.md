# R353 — подтверждённая работа DTS на LG 65NANO766QA (23.11.2026)

## Источник результата и ограничения

Подтверждение предоставлено владельцем телевизора через сообщения, снимки экрана webOS Dev Manager и Lampa, а также текстовый вывод диагностических команд. Это полевой отчёт со слов владельца, а не прямой доступ разработчика к устройству. Личные адреса, серийный номер, MAC, ключи и конфигурации в отчёт не включены.

| Атрибут | Фактически сообщённое значение |
| --- | --- |
| Модель | LG 65NANO766QA |
| Прошивка | 04.54.30 |
| webOS | webOS 22 / 7.5.7-23 |
| Ядро | `aarch64` |
| GStreamer | 1.18.2 |
| BusyBox | 1.31.1 |
| ABI мультимедиа | ELF32 little-endian ARM (`CLASS=1`, `ENDIAN=1`, `MACHINE=40 0`) для `umediaserver`, `starfish-media-pipeline`, `libgstrtkalsa.so` |

## Подтверждённые этапы

1. **R350:** исправлена ложная несовместимость, возникавшая из-за `uname -m=aarch64`. Два штатных медиабинарника на самом деле ELF32 ARM. Контрольные суммы исходных плагинов и тестовых файлов — OK.
2. **R351:** в оригинальном R278 команда `timeout -t 20` несовместима с BusyBox 1.31.1. Заменена на `timeout 20` только во временно распакованной проверенной копии. Изолированное декодирование DTS Stereo и DTS 5.1 завершилось `PASS`.
3. **R352:** AC3 декодировался как `audio/x-raw F32LE`, 48 кГц, 6 каналов, `non-interleaved`, маска `0x0000000000000c0f` через `ac3parse → avdec_ac3`, затем EOS. Проверка AC3 строго принимает этот профиль **или** исходный профиль S8 passthrough, не пропуская ошибочное подключение AlekS DTS к AC3.
4. **R352 verify на физическом LG:** `PASS dts-stereo`, `PASS dts-51`, `PASS ac3-51 (decoded-F32LE-5.1)`, `RESULT=R352_verify_PASS`.
5. **R352 install на физическом LG:** `R278 configured. Fully reboot the TV`, `RESULT=R352_install_PASS`, `INSTALL_EXIT=0`. Отдельно передан `READY=PASS`.
6. **Lampa после полной перезагрузки:** на снимке экрана выбрана английская DTS 5.1 дорожка; владелица подтвердила слышимый звук **с первого выбора после перезагрузки, без предварительного переключения на AC3**.
7. **Дополнение к полевому отчёту (23.11.2026):** владелица отдельно подтвердила, что **переключение аудиодорожек и перемотка в Lampa работают**. Это подтверждение пользовательского сценария, а не инструментальный замер; точные точки перемотки, длительность и полный перечень сочетаний кодеков не документированы.

**Вывод:** на конкретной модели/прошивке подтверждены успешная установка и слышимый DTS в Lampa после полной загрузки. Это не только лабораторное декодирование.

## Что НЕ подтверждено

- Полный вывод послестановочного `installed.sha256` и `ENV_MATCH=PASS` не присылался (отдельно подтверждён лишь `READY=PASS`). Успешный запуск и звук не заменяют побайтовую проверку состояния.
- Достоверная раскладка шести каналов на физическом HDMI/eARC/акустике (в отличие от caps в изолированном тесте).
- Длительное воспроизведение без сбоев, все сочетания переключений DTS↔AC3 и несколько циклов холодной загрузки. **Обычная перемотка и переключение аудиодорожек работают по сообщению владелицы**, но расширенная регрессия не выполнена.
- Восстановление штатного состояния после `rollback` на этом экземпляре — механизм проверен в коде, но фактический откат не выполнялся.
- Исправление холодной DTS-тишины на другом LG с webOS 26: это **отдельная нерешённая задача**, успешный запуск на webOS22 не доказывает её устранение.

## Безопасная эксплуатация и проверка без перезапуска

Установщик R352 оставлен неизменным в части `verify`, `install`, `rollback`; R353 добавляет отдельный **read-only** режим `status` для проверки `READY`, `INSTALLED_SHA256`, `ENV_MATCH`, `MEDIA_SERVICE` без печати содержимого файла окружения и без изменения служб. `R353_STATUS_PASS` означает целостность установки **по проверенным полям**, а не тест слышимого звука.

Версия R353 доступна в корне репозитория: [install-universal.sh](../install-universal.sh). Для применения режима `status` достаточно запускать этот файл в root SSH с параметром `status`; повторная установка не требуется. Используйте SHA256 и неизменяемую ссылку на коммит из [README](../README.md).

## Техническая политика универсальности

Поддержка определяется не названием модели и не `uname -m`, а фактическим ABI медиапроцессов, GStreamer, прохождением изолированных DTS/AC3 тестов, конфигурацией systemd и реальной полевой проверкой. Универсальный установщик **не гарантирует** совместимость всех LG. Оригинальный бинарный релиз R278 остаётся неизменяемым и имеет контрольные суммы. Принцип: **диагностика → проверка → резервная копия → установка → перезагрузка → полевой звук → при необходимости откат**.
