Дата: 26.11.2026. Статус: аудит; не установочный релиз.

## Компоненты

| Компонент | Условия для будущего релиза |
| --- | --- |
| Ядро DTS из публичной R278 (libdcadec + адаптер AlekS) | Сохранить LGPL-2.1-or-later для libdcadec и условия MIT для адаптера. Приложить действующие уведомления, соответствующие исходники libdcadec и материалы перелинковки. |

| GStreamer, GLib и библиотеки LG | Используются установленные на устройстве библиотеки. Не включать прошивку и штатные библиотеки LG в дистрибутив. |

Основание для перечня: публичные SOFTWARE-NOTICES R278, фактические зависимости кандидата R574 и [ABL-1.0](LICENSE-ALEKS-BINARY.md). Это план состава, а не заявление о завершённом перелицензировании.

## Проверка комплекта перелинковки R278

Оригинальные публичные архивы R278 и R278-R56-LGPL-RELINK повторно скачаны; обе контрольные суммы SHA256 совпали с опубликованными. Сценарий relink.sh выполнен в отдельном временном каталоге, с ARM GCC 13.3.0 и совместимыми библиотеками GStreamer 1.16.2. Сборка завершилась успешно.

| Проверка | Результат |
| --- | --- |
| Целостность публичных архивов | 2/2 PASS |
| Сборка libdcadec и перелинковка | PASS |
| Размер оригинального ядра | 264 004 байта |
| Размер полученного ядра | 231 280 байт |
| Побайтное совпадение ELF после удаления Build ID | НЕ СОВПАДАЕТ |
| DTS Stereo, S16LE, 48 кГц | PCM побайтно совпадает (192 512 байт) |
| DTS 5.1, S16LE, 48 кГц | PCM побайтно совпадает (577 536 байт) |
| Максимальная разница выборок | 0 LSB в обоих тестах |

**Уточнение к README.txt старого комплекта:** на проверенной версии компилятора отличие бинарников не ограничивается Build ID. Полученный файл имеет другой размер, и имеются отличия секций ELF. Причина всех различий пока не установлена. Это не отменяет проверенную возможность перелинковки. Совпадение PCM подтверждено только на двух имеющихся тестовых файлах; оно не доказывает эквивалентность на всех DTS-потоках.

Дистрибутив R574 не опубликован. Материалы закрытой обёртки, приватные исходники и системная конфигурация ТВ не распространялись. Следующие условия: подтверждение применимости ABL-1.0 к новой обёртке, комплектность уведомлений и проверка системного обновления и отката.
